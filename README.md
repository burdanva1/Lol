# Glass секундомер задач

Статическое веб-приложение в современном iPhone glass-стиле: макет из таблицы сохранён по смыслу, но интерфейс больше не выглядит как Excel.

## Возможности

- секундомер в зоне «G2» со стартом, паузой и сбросом;
- список этапов с чекбоксами слева и временем в минутах справа;
- выполненный этап подсвечивается зелёным glass-эффектом;
- значения времени используются как пороги секундомера;
- переключатель автоотметки ставит галочку, когда секундомер достиг времени этапа.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого перейдите на <http://localhost:8000>.
