# Таблица задач с секундомером

Статическое веб-приложение имитирует лист Excel с таблицей задач и секундомером в ячейке G2.

## Возможности

- секундомер в ячейке G2 со стартом, паузой и сбросом;
- чекбоксы слева от строк таблицы;
- строка статуса окрашивается в зелёный цвет после отметки чекбокса;
- значения в столбце «Время» используются как пороги в минутах;
- опция автоматической отметки выполненных строк, когда секундомер дошёл до указанного времени.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого перейдите на <http://localhost:8000>.
